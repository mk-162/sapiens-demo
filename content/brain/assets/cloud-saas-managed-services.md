## Sales use

Use when CIO/COO buyers are concerned about operational burden, resilience, release governance, environment management, disaster recovery or moving from on-prem to SaaS/cloud.

## Discovery questions

- What is the current hosting model and who owns environments, monitoring, backup and DR?
- Which operational risks are most painful: outages, release windows, skills shortages, recovery testing or security controls?
- Does the buyer need Azure/Microsoft alignment or global support evidence?
- Is this a new SaaS deployment, migration from on-prem or managed-services wrap around existing products?

## Proposal angles

- Lead with operational focus: Sapiens manages the platform so the insurer focuses on insurance.
- Package cloud services with Premium AMS for proactive release, performance and environment governance.
- Use cloud scale proof points only when current official source material is confirmed.

## Risks / validation notes

Validate current service levels, support model, certifications and commercial commitments before external use. Do not promise a specific SLA unless confirmed.
